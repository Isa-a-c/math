# 공업수학 시각화

Kreyszig 『공업수학 10판 하』 11장(Fourier 급수)과 12장(파동·열 방정식)의 개념을 함수 하나로 이어서 보여 주는 강의·출제용 프로그램입니다. 인터넷 없이 실행됩니다.

## 실행 방법 (Windows)

1. [python.org](https://www.python.org/downloads/)에서 **Python 3.10 이상**을 설치합니다. 설치 첫 화면에서 **"Add python.exe to PATH"**를 선택하십시오.
2. 이 저장소를 내려받습니다. GitHub의 **Code → Download ZIP**으로 받아 압축을 풉니다.
3. 폴더 안의 **`시각화 실행.bat`**을 더블클릭합니다.
   - 처음 한 번은 필요한 라이브러리(PySide6)를 설치합니다. 인터넷이 필요하며 몇 분 걸립니다.
   - 그다음부터는 바로 프로그램 창이 열립니다.
   - 문제가 생기면 원인(Python 없음, 설치 실패)을 보여 주고 멈춥니다.

처음 열면 화면 오른쪽 아래에 **처음 안내**가 나옵니다. 언제든 메뉴 줄의 **도움말**에서 함수 입력법, 수식 쓰는 법, 용어, 단축키를 볼 수 있습니다.

Python 없이 실행되는 프로그램 파일(약 213MB)은 용량이 커서 저장소에 넣지 않았습니다. 받은 프로그램 파일을 처음 실행할 때 Windows가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누르십시오.

## 프로그램 사용

창 제목 바로 아래 얇은 메뉴 줄에 **파일·편집·보기·도움말** 메뉴가 있고, 그 오른쪽 **시각화 · 예제 만들기 · 출력** 탭으로 화면을 바꿉니다.

**시각화 화면**
1. **문제를 정합니다.** 왼쪽 위 **문제**에서 고릅니다.

   | 고르는 것 | 값 |
   |---|---|
   | 방정식 | 없음(함수 전개) · 파동 방정식 · 열 방정식 · 라플라스 방정식(정상 상태) |
   | 영역 | 주기 (−L, L) · 구간 (0, L) · 직선 (−∞, ∞) · 직사각형 · 원판(반지름 r) · 구(Legendre, x = cos φ) |
   | 끝·변의 조건 (영역이 정함) | 구간: x = 0 끝, x = L 끝 / 직사각형: 막은 네 변, 판(라플라스)은 x = 0, x = a, y = 0 세 변 / 원판: 가장자리 / 구: 전위를 구할 곳(구 안·구 밖). 각각 고정(값 0, 온도 고정) · 자유(기울기 0, 단열), 막대와 함수 전개의 양 끝은 열 방출(x = 0에서 u_x − hu = 0, x = L에서 u_x + hu = 0)도 |
   | 감쇠 (구간의 파동) | 없음 · 있음 |

   사인 급수인지 코사인 급수인지, 급수인지 적분인지는 **고르지 않습니다.** 영역과 양 끝 조건이 정합니다(양 끝 고정 → 사인, 양 끝 자유·단열 → 코사인, 한쪽만 자유 → sin((2n−1)πx/2L), 열 방출 → tan kL = −k/h 같은 방정식의 근 kₙ, 원판 → Bessel 함수 Jₘ(αₙr/R), 구 → Legendre 다항식 Pₙ(x), 직선 → Fourier 적분). 그 아래에 교재의 어느 절인지 나오고(예: 파동 + 구간 + 고정 = **12장 · 현의 진동**), 교재에 바로 없는 조합(자유 끝 현, 감쇠 현, 한쪽 끝만 자유·단열, 열 방출 끝, 단열된 변, 자유로운 변의 막, 원판의 열전도, 원판의 cos mθ 모드)은 **응용**으로 표시됩니다. 원판에서는 함수를 r(또는 x)과 R로 쓰고 각 방향 차수 m(처음 모양 f(r)cos mθ)을 고를 수 있습니다. 구에서는 x = cos φ로 쓰거나 phi로 쓰며, L은 1로 정해져 있습니다. 다른 영역으로 가면 r, R은 x, L로, phi는 acos(x)로 바꿔 줍니다. 방정식에 맞지 않는 영역은 흐리게 보이고, 마우스를 올리면 이유가 나옵니다.
2. **함수를 입력합니다.** `x^2`, `x²`, `|x|`, `sin x`, `2x`처럼 씁니다. 칸 이름에 이 함수의 뜻과 구간(예: "초기 변위 f(x) = u(x, 0), 0 < x < L")이 나오고, 문제를 바꿔 뜻이 바뀌면 알려 줍니다. 구간마다 식이 다르면 **구간별**을 골라 "x < 끝값이면 식" 줄을 추가합니다.
3. **풀이 단계를 따라갑니다.** 단계마다 교재 수식과 그래프가 있습니다. 그래프 위 단계 줄(① → ② → ③)의 단계 이름을 누르면 그 단계의 그래프가 보입니다.
   - **변수분리와 고유값 문제:** 끝 조건이 고르는 고유함수(sin, cos, sin kₙx, Jₘ, Pₙ)를 그래프로 봅니다. 방정식이 없으면 "기저 함수", "고유함수" 단계입니다.
   - **전개:** 초기조건(또는 함수)을 고유함수로 전개합니다. 부분합 · 계수의 의미 · 계수 크기 · 수렴과 도약 중에서 골라 봅니다.
   - **해:** u(x, t)의 시간 변화를 재생합니다. 라플라스 방정식은 판을 위에서 본 온도와 가로줄마다의 온도, 원판은 위에서 본 모양과 반지름 방향 단면, 구는 z축을 지나는 단면과 반지름마다의 전위를 봅니다.

   문제를 바꾼 것은 Ctrl+Z로 되돌립니다.
4. **그래프를 봅니다.**
   - **고정(비교):** 지금 결과를 남겨 바꾼 결과와 비교합니다.
   - **보기:** 마우스 위치의 값을 읽습니다. Ctrl+휠로 확대, 끌어서 이동, 더블클릭으로 원래대로 돌아갑니다.
   - **키보드:** 그래프를 누른 뒤 ←→ 값 읽기, +/− 확대, Enter 점 표시를 씁니다.
   - **펜 / 점:** 그래프 위에 표시합니다. 담은 그림에도 함께 들어갑니다.
   - **그래프 담기:** 지금 장면을 예제의 그림으로 넣습니다.

   아래 탭에서 요약(그래프 값 표 포함)과 개념 설명을 보고, 개념 설명은 **고치기**로 바꿀 수 있습니다.

**예제 만들기 · 출력 화면**
5. **예제를 만듭니다.** 소문항을 더하고 문장·배점·풀이 메모를 직접 씁니다. 수식은 `$a_n = \frac{1}{L}\int_{-L}^{L} f\,dx$`처럼 씁니다. 다룰 수 있는 함수는 자동 풀이에 일반항과 부분적분 과정이 들어갑니다.
6. **출력합니다.** **이 예제 담기**로 모은 뒤 **Word로 출력**이나 **PDF로 출력**을 누릅니다. 풀이를 빼면 문제지가 됩니다. Word 그림은 **도형으로 변환**해 고칠 수 있습니다.
7. **저장과 되돌리기.** 만든 예제와 고친 설명은 프로그램을 닫아도 남습니다. 지운 것은 알림의 **되돌리기**나 Ctrl+Z로 되살리고, **예제 모음 저장/열기**로 파일로 주고받습니다.

단축키: F 발표 모드, Space 재생·일시정지, Ctrl+Z 되돌리기, Esc 닫기.

자세한 설명과 파일 구성은 [studio/README.md](studio/README.md)에 있습니다.
