# 공업수학 시각화

Kreyszig 『공업수학 10판 하』 11장(Fourier 급수)과 12장(파동·열 방정식)의 개념을 함수 하나로 이어서 보여 주는 강의·출제용 프로그램입니다. 인터넷 없이 실행됩니다.

## 실행 방법 (Windows)

1. [python.org](https://www.python.org/downloads/)에서 **Python 3.10 이상**을 설치합니다. 설치 첫 화면에서 **"Add python.exe to PATH"**를 선택하십시오.
2. 이 저장소를 내려받습니다. GitHub의 **Code → Download ZIP**으로 받아 압축을 풉니다.
3. 폴더 안의 **`시각화 실행.bat`**을 더블클릭합니다.
   - 처음 한 번은 필요한 라이브러리(PySide6)를 설치합니다. 인터넷이 필요하며 몇 분 걸립니다.
   - 그다음부터는 바로 프로그램 창이 열립니다.
   - 문제가 생기면 원인(Python 없음, 설치 실패)을 보여 주고 멈춥니다.

처음 열면 화면 오른쪽 아래에 **처음 안내**가 나옵니다. 언제든 메뉴 줄의 **도움말**에서 함수 입력법, 수식 쓰는 법, 용어, 단축키를 볼 수 있습니다.

Python 없이 실행되는 프로그램 파일(약 213MB)은 용량이 커서 저장소에 넣지 않았습니다. 받은 프로그램 파일을 처음 실행할 때 Windows가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누르십시오.

## 프로그램 사용

창 제목 바로 아래 얇은 메뉴 줄에서 **파일·편집·보기·도움말** 메뉴와 **시각화 · 예제 만들기 · 출력** 화면을 고릅니다.

**시각화 화면**
1. **함수를 입력합니다.** 왼쪽 위에 `x^2`, `x²`, `|x|`, `sin x`, `2x`처럼 씁니다. 구간마다 식이 다르면 **구간별**을 골라 "x < 끝값이면 식" 줄을 추가합니다. 입력한 식은 아래에 교재처럼 보입니다.
2. **개념을 더합니다.** 기본 개념은 **Fourier 급수**(함수를 sin, cos 파동들의 합으로 나타냄)입니다. **개념 더하기**에서 개념을 하나씩 더하면 교재의 다른 절이 됩니다.

   | 더할 개념 | 고르는 것 |
   |---|---|
   | 반구간 전개 | 사인(기함수 확장) · 코사인(우함수 확장) |
   | Fourier 적분 | 적분의 위끝 a |
   | 급수 분석 | 계수의 의미 · 계수 크기 · 수렴과 도약 |
   | 시간 변화 | 파동 방정식 · 열 방정식, 양 끝(고정 · 자유/단열 · 무한히 긺) |
   | 2차원 막 | 막의 세로 길이, 처음 모양 |
   | 감쇠 | 감쇠 계수 k |

   예를 들어 Fourier 급수 **+ 시간 변화(파동)**는 **12장 · 현의 진동**, 여기에 **+ 2차원 막**을 더하면 **직사각형 막의 진동**, **+ 시간 변화(열, 무한히 긺)**는 **무한히 긴 막대의 열전도(열핵)**입니다. 지금 조합의 이름이 카드 아래에 나오고, 교재에 바로 없는 조합(예: 자유 끝 + 감쇠 현, 현의 진동 + 처음 모양의 계수 크기)은 **응용 조합**으로 표시됩니다.

   - 더한 개념은 카드로 쌓입니다. 카드 이름을 누르면 그 개념의 그래프와 설정이 펼쳐지고, 나머지 카드는 한 줄로 접힙니다. × 로 뺍니다.
   - 시간 변화가 있으면 반구간 전개는 양 끝 조건이 정합니다(고정 → 사인, 자유·단열 → 코사인).
   - 함께 바꿔야 하는 개념은 자동으로 바뀌고(예: 2차원 막을 더하면 시간 변화 = 파동, 양 끝 = 고정) 상태 줄에 알려 줍니다. Ctrl+Z로 되돌립니다.
   - 장이 늘어도 더할 개념이나 그 값만 늘어나므로 목록이 길어지지 않습니다.
3. **그래프를 봅니다.**
   - **고정(비교):** 지금 결과를 남겨 바꾼 결과와 비교합니다.
   - **보기:** 마우스 위치의 값을 읽습니다. Ctrl+휠로 확대, 끌어서 이동, 더블클릭으로 원래대로 돌아갑니다.
   - **키보드:** 그래프를 누른 뒤 ←→ 값 읽기, +/− 확대, Enter 점 표시를 씁니다.
   - **펜 / 점:** 그래프 위에 표시합니다. 담은 그림에도 함께 들어갑니다.
   - **그래프 담기:** 지금 장면을 예제의 그림으로 넣습니다.

   아래 탭에서 요약(그래프 값 표 포함)과 개념 설명을 보고, 개념 설명은 **고치기**로 바꿀 수 있습니다.

**예제 만들기 · 출력 화면**
4. **예제를 만듭니다.** 소문항을 더하고 문장·배점·풀이 메모를 직접 씁니다. 수식은 `$a_n = \frac{1}{L}\int_{-L}^{L} f\,dx$`처럼 씁니다. 다룰 수 있는 함수는 자동 풀이에 일반항과 부분적분 과정이 들어갑니다.
5. **출력합니다.** **이 예제 담기**로 모은 뒤 **Word로 출력**이나 **PDF로 출력**을 누릅니다. 풀이를 빼면 문제지가 됩니다. Word 그림은 **도형으로 변환**해 고칠 수 있습니다.
6. **저장과 되돌리기.** 만든 예제와 고친 설명은 프로그램을 닫아도 남습니다. 지운 것은 알림의 **되돌리기**나 Ctrl+Z로 되살리고, **예제 모음 저장/열기**로 파일로 주고받습니다.

단축키: F 발표 모드, Space 재생·일시정지, Ctrl+Z 되돌리기, Esc 닫기.

자세한 설명과 파일 구성은 [studio/README.md](studio/README.md)에 있습니다.
