# 공업수학 시각화

Kreyszig 『공업수학 10판 하』 11장(Fourier 급수)과 12장(파동·열 방정식)의 개념을 함수 하나로 이어서 보여 주는 강의·출제용 프로그램입니다. 인터넷 없이 실행됩니다.

## 실행 방법 (Windows)

1. [python.org](https://www.python.org/downloads/)에서 **Python 3.10 이상**을 설치합니다. 설치 첫 화면에서 **"Add python.exe to PATH"**를 선택하십시오.
2. 이 저장소를 내려받습니다. GitHub의 **Code → Download ZIP**으로 받아 압축을 풉니다.
3. 폴더 안의 **`시각화 실행.bat`**을 더블클릭합니다.
   - 처음 한 번은 필요한 라이브러리(PySide6)를 설치합니다. 인터넷이 필요하며 몇 분 걸립니다.
   - 그다음부터는 바로 프로그램 창이 열립니다.
   - 문제가 생기면 원인(Python 없음, 설치 실패)을 보여 주고 멈춥니다.

처음 열면 화면 오른쪽 아래에 **처음 안내**가 나옵니다. 언제든 위쪽 **도움말**에서 함수 입력법, 수식 쓰는 법, 용어, 단축키를 볼 수 있습니다.

Python 없이 실행되는 프로그램 파일(약 213MB)은 용량이 커서 저장소에 넣지 않았습니다. 받은 프로그램 파일을 처음 실행할 때 Windows가 "PC 보호" 창을 띄우면 **추가 정보 → 실행**을 누르십시오.

## 프로그램 사용

1. **함수를 입력합니다.** 왼쪽 위에 `x^2`, `sin x`, `2x`처럼 씁니다. 구간마다 식이 다르면 **구간별**을 골라 "x < 끝값이면 식" 줄을 추가합니다. 입력한 식은 아래에 교재처럼 보입니다. `k*x`처럼 새 글자를 쓰면 값을 넣는 칸이 생깁니다.
2. **개념을 고릅니다.** 개념은 나무 모양입니다(Fourier 급수 → 계수의 의미·계수 크기 / 수렴과 도약 / 반구간 전개 → 현의 진동·막대의 열전도). 체크하면 그래프가 그 개념으로 바뀌고, Fourier 급수에서 그 개념까지의 경로만 켜집니다. 위쪽 **다음 개념 →**(또는 → 키)으로 수업 순서대로 진행합니다.
3. **그래프를 봅니다.** 그래프 위 도구로 다음을 할 수 있습니다.
   - **고정:** 지금 결과를 남겨 바꾼 결과와 비교합니다.
   - **보기:** 마우스 위치의 값을 읽습니다. Ctrl+휠로 확대, 끌어서 이동, 더블클릭으로 원래대로 돌아갑니다.
   - **펜 / 점:** 그래프 위에 표시합니다.

   현과 막대는 그래프 아래 ▶ ⏸ ■로 재생합니다.
4. **설명과 예제를 봅니다.** 그래프 아래 탭에서 **요약**, **개념** 설명, **예제 만들기**를 엽니다.
   - **개념 설명 고치기:** 개념 설명은 **고치기**로 바꿀 수 있습니다.
   - **예제 만들기:** 소문항을 더하고 문장·배점·풀이 메모를 직접 씁니다.
   - **수식 쓰기:** 수식은 `$a_n = \frac{1}{L}\int_{-L}^{L} f\,dx$`처럼 씁니다.
   - **그림:** **그래프 담기**로 원하는 장면을 그림으로 넣습니다.
5. **Word로 출력합니다.**
   - **담기:** **이 예제 담기**로 예제를 모읍니다.
   - **출력:** **Word로 출력**을 누르면 개념 설명·그래프·문제·풀이가 한 문서로 나옵니다.
   - **문제지:** 풀이를 빼면 문제지가 됩니다.
   - **저장:** 만든 예제와 고친 설명은 프로그램을 닫아도 남고, **예제 모음 저장/열기**로 파일로 주고받습니다.

단축키: F 발표 모드, Space 재생·일시정지, ←/→ 이전·다음 개념, Esc 발표 끝내기.

자세한 설명과 파일 구성은 [studio/README.md](studio/README.md)에 있습니다.
