# 공업수학 시각화

Kreyszig 『공업수학 10판 하』 11·12장의 개념을 함수 하나로 이어서 보여 주는 프로그램입니다. 인터넷 없이 실행됩니다.

## 실행

저장소 폴더의 `시각화 실행.bat`을 더블클릭합니다(처음 한 번 PySide6 설치). 처음 열면 안내가 나오고, 위쪽 **도움말**에서 다시 볼 수 있습니다. **처음 상태로**는 함수와 설정만 처음으로 돌리고(되돌리기 가능), 만든 예제와 고친 설명은 그대로 둡니다.

## 쓰는 순서

1. **함수를 입력합니다.** `x^2`, `sin x`, `2x`처럼 수식으로 쓰고, 구간마다 식이 다르면 **구간별**을 골라 "x < 끝값이면 식" 줄을 추가합니다. 입력한 식은 아래에 교재처럼 보입니다. 새 글자(`k*x`의 `k`)를 쓰면 값을 넣는 칸이 생깁니다. 입력한 함수가 곧 예제입니다.
2. **개념을 체크합니다.** Fourier 급수가 기본입니다. 그래프는 한 칸이며, 체크하면 그 개념의 그래프로 바뀝니다(앞 개념의 설정은 그대로 반영). 체크하면 그 개념의 바탕 개념만 남고 겹치지 않는 개념은 해제됩니다(예: 막대를 켜면 현은 해제되고 공통 바탕인 반구간 전개는 남음). 끄면 바탕 개념으로 돌아갑니다. 요약·개념·풀이와 Word에는 체크된 개념이 모두 들어갑니다.
   - 11장: 계수의 의미(직교성), 계수 크기, 수렴과 도약, 반구간 전개
   - 12장: 현의 진동, 막대의 열전도. 유한한 현·막대를 켜면 그 바탕인 반구간 전개가 함께 켜집니다. 무한히 긴 현·막대도 고를 수 있습니다.
3. **결과를 봅니다.** 그래프 위 도구로 **고정**(지금 결과를 남겨 바꾼 결과와 겹치거나 나란히 비교), **보기**(마우스 위치의 값, Ctrl+휠 확대, 끌어서 이동, 더블클릭 원래대로), **펜**, **점**을 씁니다. 왼쪽 **그래프 범위**에서 축과 현·막대의 끝 시간을 정합니다. 시간이 있는 개념은 ▶ ⏸ ■로 재생합니다.
4. **예제를 만듭니다.** 아래 **예제 만들기** 탭에서 소문항(급수 구하기, 역문제, 그래프 읽기, 계수, 현·막대의 해, 자유 문항)을 더하고 문장·배점·풀이 메모를 직접 씁니다. 자동 문장은 초안이며, 고치지 않은 문장은 설정을 바꾸면 따라 바뀝니다. **그래프 담기**로 원하는 장면을 그림으로 고르고 설명과 크기를 정합니다. **이 예제 담기**로 모으고, 담은 예제는 **고치기**로 다시 엽니다.
5. **개념 설명을 고칩니다.** **개념** 탭의 **고치기**로 설명 글을 바꿉니다. 수식은 `$a_n$`, `$\frac{1}{L}\int_{-L}^{L} f\,dx$`처럼 쓰고, `$$…$$` 문단은 가운데 수식입니다.
6. **출력하고 저장합니다.** **Word로 출력**에 개념 설명·그래프·풀이를 고르고, 머리말·학번 이름 칸·답 쓰는 칸 크기를 정합니다. 풀이를 빼면 문제지가 됩니다. 만든 예제와 고친 설명은 프로그램을 닫아도 남고, **예제 모음 저장/열기**로 파일로 주고받습니다.

단축키: F 발표 모드, Space 재생·일시정지, Esc 발표 끝내기.

## 실행과 만들기

```
python app.py                         # 소스로 실행 (PySide6 필요)
python app.py --self-test report.json # 계산·화면·Word 출력 자체 검사
powershell -File build.ps1            # 실행 파일 만들기
```

## 구성

| 파일 | 역할 |
|---|---|
| `app.py` | 프로그램 창(Qt WebEngine), Word 저장, 자체 검사 |
| `web/studio.html`, `web/studio.js` | 설정 화면, 그래프, 요약, 문제와 풀이, Word 출력 |
| `web/concepts.js` | 개념 목록과 개념 설명 |
| `web/docx.js` | 화면용 수식과 Word 수식, Word 파일 만들기 |
| `web/math.js` | 수식 해석, 급수, 파동·열 계산 (화면과 무관) |
| `web/plot.js`, `web/style.css` | 그래프 그리기, 화면 모양 |
| `web/test.html` | 교재 값과 닫힌 해로 계산 검사 |

새 개념은 `web/concepts.js`의 `CONCEPTS`와 `CONCEPT_TEXT`에 넣고, `web/studio.js`에 그래프(`PANELS`), 요약, 문제와 풀이를 추가합니다.
