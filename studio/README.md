# 공업수학 시각화

Kreyszig 『공업수학 10판 하』 11·12장의 개념을 함수 하나로 이어서 보여 주는 프로그램입니다. 인터넷 없이 실행됩니다.

## 실행

저장소 폴더의 `시각화 실행.bat`을 더블클릭합니다(처음 한 번 PySide6 설치). 처음 열면 안내가 나오고, 메뉴 줄의 **도움말**에서 다시 볼 수 있습니다. **처음 상태로**는 함수와 설정만 처음으로 돌리고(되돌리기 가능), 만든 예제와 고친 설명은 그대로 둡니다.

## 화면

창 제목 아래 메뉴 줄에서 **시각화 · 예제 만들기 · 출력** 화면을 고릅니다.

## 쓰는 순서

1. **문제를 정합니다.** 방정식(없음·파동·열), 영역(주기·구간·직선·직사각형), 양 끝 조건(고정·자유/단열), 감쇠를 고릅니다. 사인·코사인 급수나 적분은 영역과 양 끝 조건이 정하며, 교재의 어느 절인지(예: 12장 · 현의 진동) 또는 응용인지 보입니다. 예전 파일(개념 체크, 조건 축)도 문제로 읽습니다.
2. **함수를 입력합니다.** `x^2`, `sin x`, `2x`처럼 쓰고, 구간마다 식이 다르면 **구간별**을 고릅니다. 칸 이름에 f(x)의 뜻(초기 변위, 초기 온도 등)과 구간이 나옵니다. 새 글자(`k*x`의 `k`)를 쓰면 값을 넣는 칸이 생깁니다. 풀이 단계(변수분리와 고유값 문제 → 전개 → 해)마다 교재 수식과 그래프가 있고, 그래프 위 단계 줄로 오갑니다.
3. **결과를 봅니다.** 그래프 위 도구로 **고정**(지금 결과를 남겨 바꾼 결과와 겹치거나 나란히 비교), **보기**(마우스 위치의 값, Ctrl+휠 확대, 끌어서 이동, 더블클릭 원래대로), **펜**, **점**을 씁니다. 왼쪽 **그래프 범위**에서 축과 현·막대의 끝 시간을 정합니다. 시간이 있는 개념은 ▶ ⏸ ■로 재생합니다.
4. **예제를 만듭니다.** 아래 **예제 만들기** 탭에서 소문항(급수 구하기, 역문제, 그래프 읽기, 계수, 현·막대의 해, 자유 문항)을 더하고 문장·배점·풀이 메모를 직접 씁니다. 자동 문장은 초안이며, 고치지 않은 문장은 설정을 바꾸면 따라 바뀝니다. **그래프 담기**로 원하는 장면을 그림으로 고르고 설명과 크기를 정합니다. **이 예제 담기**로 모으고, 담은 예제는 **고치기**로 다시 엽니다.
5. **개념 설명을 고칩니다.** **개념** 탭의 **고치기**로 설명 글을 바꿉니다. 수식은 `$a_n$`, `$\frac{1}{L}\int_{-L}^{L} f\,dx$`처럼 쓰고, `$$…$$` 문단은 가운데 수식입니다.
6. **출력하고 저장합니다.** **Word로 출력**에 개념 설명·그래프·풀이를 고르고, 머리말·학번 이름 칸·답 쓰는 칸 크기를 정합니다. 풀이를 빼면 문제지가 됩니다. 만든 예제와 고친 설명은 프로그램을 닫아도 남고, **예제 모음 저장/열기**로 파일로 주고받습니다.

단축키: F 발표 모드, Space 재생·일시정지, Esc 발표 끝내기.

## 실행과 만들기

```
python app.py                         # 소스로 실행 (PySide6 필요)
python app.py --self-test report.json # 계산·화면·Word·PDF 출력 자체 검사
python release.py                     # 빌드, ZIP, 한글 경로 배포 검사까지 한 번에 (저장소 폴더의 .venv로 실행)
```

## 구성

| 파일 | 역할 |
|---|---|
| `app.py` | 프로그램 창(Qt WebEngine), Word·PDF 저장, 자체 검사 |
| `release.py`, `build.ps1` | 배포본 만들기(빌드, ZIP, 배포 검사) |
| `web/studio.html` | 화면 구성 |
| `web/core.js` | 상태, 값 읽기, 계산(급수, 현, 막, 막대, Fourier 적분), 정확한 값 |
| `web/draw.js`, `web/svg.js` | 그래프(개념마다 한 칸)와 Word용 SVG 그림 |
| `web/content.js`, `web/symbolic.js` | 요약, 문제와 풀이, 일반항(기호 계산) |
| `web/store.js` | 저장(자동·예제 모음 파일)과 Word·PDF 출력 |
| `web/ui.js` | 설정 화면, 탭, 예제 편집기, 안내, 입력 처리 |
| `web/selftest.js` | 화면 자체 검사(검사할 때만 불러옴) |
| `web/version.js` | 버전 |
| `web/problem.js` | 문제 모델: 방정식·영역(`EQUATIONS`, `DOMAINS`), 교재의 절(`SECTIONS`), 풀이 단계와 수식(`stagesOf`), 계산용 값 만들기(`applyProblem`), 예전 파일 읽기 |
| `web/concepts.js` | 개념 설명 |
| `web/docx.js` | 화면용 수식과 Word 수식, Word 파일 만들기 |
| `web/math.js` | 수식 해석, 급수, 파동·열 계산 (화면과 무관) |
| `web/plot.js`, `web/style.css` | 그래프 그리기, 화면 모양 |
| `web/test.html` | 교재 값과 닫힌 해로 계산 검사 |

새 주제는 먼저 문제 모델에 넣습니다: 풀 수 있는 방정식·영역은 `web/problem.js`의 `EQUATIONS`·`DOMAINS`, 교재의 절 이름은 `SECTIONS`(데이터 표), 풀이 단계와 수식은 `stagesOf`, 계산 엔진에 넘길 값은 `applyProblem`입니다. 그다음 설명은 `web/concepts.js`, 계산은 `web/core.js`, 그래프는 `web/draw.js`의 `PANELS`, 요약과 문제·풀이는 `web/content.js`에 추가합니다.
